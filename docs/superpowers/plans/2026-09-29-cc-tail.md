# cc-tail 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在另一个终端运行 `cc-tail`，实时跟踪所有活跃 Claude Code 会话正在执行的 Bash 命令与日志，命令卡住时在超时前提醒。

**Architecture:** `sources.py`（解析 sessions/jsonl/cmdline/日志）与 `procs.py`（psutil）是仅有的两个接触真实系统的模块；
`detect.py` 是纯函数判定；`model.py` 的 `Tracker` 每个 tick 汇总数据源、维护命令与事件；`stream.py` 与 `tui.py`
是两种展示；`cc-tail.py` 是 typer 入口。实现放在 yyscripts 子模块，env 仓库通过 `bin/cc-tail` 软链到 `wrapper.sh`。

**Tech Stack:** Python 3.14（yyscripts venv）、textual 8.2.8、psutil 7.2.2、wcwidth 0.9.1、rich、typer、pytest。

**Spec:** `docs/superpowers/specs/2026-09-29-cc-tail-design.md`

## Global Constraints

- 所有代码在 git submodule `package/yyscripts` 中（分支 master），测试用 `package/yyscripts/venv/bin/python -m pytest`，不要用系统 python。

## 与 spec 的差异（实现原型时发现，已验证）

- **状态判定输入**：`classify()` 接收 `Activity`（输出/CPU 最近一次增长的时间戳）而不是完整采样历史，等价且省内存。
- **🟡 安静工作**：定义为「输出超过 3 秒未增长、且未达到其它状态」，不再要求 CPU 在涨；否则「两者都不涨但未到卡死阈值」无状态可归。
- **轮询豁免**：只认 `sleep`/`gsleep` 进程；`wait` 是 shell 内建命令，不会出现在进程树里。
- **通知**：`--notify osc` 只发 OSC 9 + BEL，不发 OSC 777——两者都支持的终端（Ghostty）会弹两次。
- **后台命令退出码**：来自 jsonl 里 `queue-operation` 记录的 `<task-notification>`（真实数据中写法有 `completed (exit code 0)` 与 `failed with exit code 144` 两种，status 取值 completed/failed/killed/stopped）。
- **L= 提取**：支持展开同一命令中先前的简单赋值（`SP=/x; L=$SP/a.log`），真实会话里这种写法很常见。
- **新增模块** `cctail/fmt.py`（两种界面共用的格式化）与测试辅助 `tests/cc_tail_fixtures.py`；fmt/notify/stream 的测试合并在 `tests/test_cc_tail_stream.py`。
- macOS 上 `/bin/sh` 的进程名是 `bash`，识别命令名一律用 `argv[0]` 的 basename。

## Review Focus

- **同一会话里两条原文相同的命令并发执行**（如两个 subagent 各跑 `sleep 60`）：应各自配对到不同的 tool_use，而不是合并或串号。→ Task 5 `test_identical_commands_bind_to_distinct_tool_uses`
- **日志被重新 `> $L` 截断、被删除、含非 UTF-8 字节或 `\r` 进度条**：跟随不崩溃、从头继续、乱码用替换字符、进度条只显示最后一段。→ Task 3 `test_line_follower_partial_truncate_and_binary`、`test_read_tail_drops_partial_first_line_and_cr`
- **`cc-tail --stream | rg xxx`**：管道里不能出现 ANSI 颜色或 OSC 通知序列。→ Task 6 `test_stream_lines_alignment_alert_and_end`（断言无 `\x1b`）与 `test_notifier_modes`（writer 为 None 时不写）
- **窄终端与改变终端大小**：60 列时命令列不小于最小宽度，放大后列宽随之更新。→ Task 7 `test_narrow_terminal`
- **启动时会话 jsonl 很大（几十 MB）**：首次全量扫描要快（子串预检后才解析）。→ Task 3 `test_jsonl_tail_large_file_is_fast`

`package/yyscripts/cctail/cells.py`：

```python
"""按终端显示宽度处理字符串：宽度一律用 wcwidth 计算（中文、emoji 占 2 列）。

East Asian Ambiguous 字符（… · — ↑ ↓ ─ │）按 1 列计，前提是终端没有开启
「ambiguous 按宽字符显示」（各终端默认如此）。
"""

from typing import Literal

from wcwidth import wcswidth, wcwidth

ELLIPSIS = "…"


def width(s: str) -> int:
    """字符串的显示列数；含不可打印字符时逐字符兜底，负值按 0 计。"""
    w = wcswidth(s)
    if w >= 0:
        return w
    return sum(max(wcwidth(ch), 0) for ch in s)


def fit(s: str, n: int, align: Literal["left", "right"] = "left") -> str:
    """把 s 截断/补齐到恰好 n 列：超长时末尾换成 …，截断点落在宽字符中间时用空格补齐。"""
    if n <= 0:
        return ""
    s = s.replace("\n", " ").replace("\t", " ")
    if width(s) > n:
        budget = n - width(ELLIPSIS)
        out = ""
        for ch in s[: n * 4]:
            if width(out + ch) > budget:
                break
            out += ch
        s = out + ELLIPSIS
    pad = " " * (n - width(s))
    return s + pad if align == "left" else pad + s
```

```python
"""cctail.procs：唯一使用真实进程的测试（本机临时子进程，无副作用）。"""

import os
import socket
import subprocess
import time

from cctail.procs import PsutilProcs


def test_tree_children_alive():
    ps = PsutilProcs()
    p = subprocess.Popen(["/bin/sh", "-c", "sleep 30; true"])
    try:
        deadline = time.time() + 5
        tree = []
        while time.time() < deadline:
            tree = ps.tree(p.pid)
            if any(i.name == "sleep" for i in tree):
                break
            time.sleep(0.05)
        assert tree[0].pid == p.pid and tree[0].argv[0] == "/bin/sh"   # macOS 的 /bin/sh 进程名是 bash
        sleep = next(i for i in tree if i.name == "sleep")
        assert sleep.argv == ("sleep", "30") and sleep.ppid == p.pid and sleep.cpu >= 0
        assert p.pid in [c.pid for c in ps.children(os.getpid())]
        assert ps.alive(p.pid)
    finally:
        p.kill()
        p.wait()
    assert not ps.alive(p.pid)
    assert ps.tree(p.pid) == []
    assert ps.children(p.pid) == []


def test_listening_flag():
    ps = PsutilProcs()
    with socket.socket() as s:
        s.bind(("127.0.0.1", 0))
        assert not ps.tree(os.getpid())[0].listening
        s.listen()
        assert ps.tree(os.getpid())[0].listening
```

```python
"""进程信息：唯一接触 psutil 的模块，对外只暴露纯数据类 ProcInfo，测试用 FakeProcs 替换。

psutil 在 macOS 上通过 libproc/sysctl 原生取数，不调用 ps、lsof 等外部程序。
"""

from dataclasses import dataclass
from typing import Protocol

import psutil


@dataclass(frozen=True)
class ProcInfo:
    pid: int
    ppid: int
    name: str
    argv: tuple[str, ...]
    cpu: float        # user + system 累计秒数
    status: str       # psutil 状态：running / sleeping / stopped / zombie …
    listening: bool   # 是否有 TCP/UDP 套接字处于 LISTEN


class ProcProvider(Protocol):
    def alive(self, pid: int) -> bool: ...
    def children(self, pid: int) -> list[ProcInfo]: ...
    def tree(self, pid: int) -> list[ProcInfo]: ...


def _info(p: psutil.Process) -> ProcInfo | None:
    try:
        with p.oneshot():
            t = p.cpu_times()
            try:
                listening = any(c.status == psutil.CONN_LISTEN for c in p.net_connections(kind="inet"))
            except psutil.Error:
                listening = False
            return ProcInfo(p.pid, p.ppid(), p.name(), tuple(p.cmdline()), t.user + t.system, p.status(), listening)
    except psutil.Error:
        return None


class PsutilProcs:
    def alive(self, pid: int) -> bool:
        try:
            return psutil.Process(pid).status() != psutil.STATUS_ZOMBIE
        except psutil.Error:
            return False

    def children(self, pid: int) -> list[ProcInfo]:
        """直接子进程。"""
        try:
            kids = psutil.Process(pid).children()
        except psutil.Error:
            return []
        return [i for i in map(_info, kids) if i is not None]

    def tree(self, pid: int) -> list[ProcInfo]:
        """pid 自身 + 全部后代；已消失的进程跳过。"""
        try:
            root = psutil.Process(pid)
            procs = [root, *root.children(recursive=True)]
        except psutil.Error:
            return []
        return [i for i in map(_info, procs) if i is not None]
```

```python
"""cc-tail 测试共用的构造数据：按 Claude Code 2.1.284 的真实格式生成，不读真实会话。"""

import json
from pathlib import Path

from cctail.procs import ProcInfo

SNAP = "/Users/u/.claude/shell-snapshots/snapshot-zsh-1-x.sh"


def eval_quote(cmd: str) -> str:
    return "'" + cmd.replace("'", "'\"'\"'") + "'"


def shell_argv(cmd: str, heredoc: bool = False) -> tuple[str, ...]:
    """Claude 执行 Bash 命令时 zsh 进程的 argv；heredoc=True 时没有 < /dev/null。"""
    stdin = "" if heredoc else " < /dev/null"
    script = (f"source {SNAP} 2>/dev/null || true && export X='1'\n: && setopt NO_EXTENDED_GLOB 2>/dev/null "
              f"|| true && eval {eval_quote(cmd)}{stdin} && pwd -P >| /tmp/claude-ab12-cwd")
    return ("/opt/homebrew/bin/zsh", "-c", script)


def iso(t: float) -> str:
    from datetime import datetime, timezone
    return datetime.fromtimestamp(t, timezone.utc).isoformat().replace("+00:00", "Z")


def rec_tool_use(tid, cmd, t, description="", timeout=None, background=False) -> dict:
    inp = {"command": cmd, "description": description}
    if timeout is not None:
        inp["timeout"] = timeout
    if background:
        inp["run_in_background"] = True
    return {"type": "assistant", "timestamp": iso(t),
            "message": {"role": "assistant", "content": [{"type": "tool_use", "id": tid, "name": "Bash", "input": inp}]}}


def rec_result(tid, text, t, is_error=False) -> dict:
    return {"type": "user", "timestamp": iso(t),
            "message": {"role": "user", "content": [
                {"type": "tool_result", "tool_use_id": tid, "content": text, "is_error": is_error}]}}


def rec_task_done(tid, t, exit_code=0, status="completed") -> dict:
    """summary 的两种真实写法：completed (exit code 0) / failed with exit code 144。"""
    tail = f"completed (exit code {exit_code})" if status == "completed" else f"{status} with exit code {exit_code}"
    content = (f"<task-notification>\n<task-id>b1</task-id>\n<tool-use-id>{tid}</tool-use-id>\n"
               f"<status>{status}</status>\n<summary>Background command \"x\" {tail}</summary>\n"
               f"</task-notification>")
    return {"type": "queue-operation", "operation": "enqueue", "timestamp": iso(t), "content": content}


def bg_receipt(path: str) -> str:
    return (f"Command running in background with ID: b1. Output is being written to: {path}. "
            f"You will be notified when it completes.")


class ClaudeDir:
    """临时的 ~/.claude：sessions/<pid>.json 与 projects/<proj>/<sid>.jsonl。"""

    def __init__(self, root: Path):
        self.root = root
        (root / "sessions").mkdir(parents=True)
        (root / "projects" / "-tmp-proj").mkdir(parents=True)

    def add_session(self, pid: int, sid: str, name: str, cwd: str = "/tmp/proj") -> None:
        (self.root / "sessions" / f"{pid}.json").write_text(
            json.dumps({"pid": pid, "sessionId": sid, "cwd": cwd, "kind": "interactive", "name": name}))

    def jsonl(self, sid: str, sub: str | None = None) -> Path:
        base = self.root / "projects" / "-tmp-proj"
        if sub:
            (base / sid / "subagents").mkdir(parents=True, exist_ok=True)
            return base / sid / "subagents" / f"{sub}.jsonl"
        return base / f"{sid}.jsonl"

    def append(self, sid: str, *records: dict, sub: str | None = None) -> None:
        with self.jsonl(sid, sub).open("a") as f:
            for r in records:
                f.write(json.dumps(r, ensure_ascii=False) + "\n")


class FakeProcs:
    """ProcProvider 的测试替身：直接设置存活 pid、子进程与进程树。"""

    def __init__(self):
        self.alive_pids: set[int] = set()
        self.kids: dict[int, list[ProcInfo]] = {}
        self.trees: dict[int, list[ProcInfo]] = {}

    def alive(self, pid: int) -> bool:
        return pid in self.alive_pids

    def children(self, pid: int) -> list[ProcInfo]:
        return list(self.kids.get(pid, []))

    def tree(self, pid: int) -> list[ProcInfo]:
        return list(self.trees.get(pid, []))

    def run(self, claude_pid: int, pid: int, cmd: str, *, heredoc=False, tree_extra=(), cpu=0.0) -> ProcInfo:
        """让 claude_pid 下出现一条正在执行的命令，其进程树 = zsh + tree_extra。"""
        sh = ProcInfo(pid, claude_pid, "zsh", shell_argv(cmd, heredoc), cpu, "sleeping", False)
        self.kids.setdefault(claude_pid, []).append(sh)
        self.trees[pid] = [sh, *tree_extra]
        return sh

    def finish(self, claude_pid: int, pid: int) -> None:
        self.kids[claude_pid] = [p for p in self.kids.get(claude_pid, []) if p.pid != pid]
        self.trees.pop(pid, None)


def proc(pid, name, *args, ppid=1, cpu=0.0, listening=False, status="sleeping") -> ProcInfo:
    return ProcInfo(pid, ppid, name, (name, *args), cpu, status, listening)
```

```python
"""解析 Claude Code 的本地数据：sessions/*.json、会话 jsonl、Bash 命令进程的 cmdline、日志文件。

全部是 Claude Code 内部格式（2.1.284 实测），官方不保证跨版本稳定。格式说明见 env 仓库
docs/superpowers/specs/2026-09-29-cc-tail-design.md 的「背景事实」。
"""

import json
import os
import re
import stat
from dataclasses import dataclass
from datetime import datetime
from pathlib import Path

# ---------- sessions/*.json ----------

@dataclass(frozen=True)
class SessionInfo:
    pid: int
    session_id: str
    name: str
    cwd: str


def read_sessions(sessions_dir: Path) -> list[SessionInfo]:
    """读取 ~/.claude/sessions/<pid>.json；损坏或缺字段的文件跳过。不检查 pid 是否存活。"""
    out = []
    for f in sorted(sessions_dir.glob("*.json")):
        try:
            d = json.loads(f.read_text())
            sid = str(d["sessionId"])
            out.append(SessionInfo(int(d["pid"]), sid, str(d.get("name") or sid[:8]), str(d.get("cwd") or "")))
        except (OSError, ValueError, KeyError, TypeError):
            continue
    return out


# ---------- Bash 命令进程的 cmdline ----------

SHELLS = {"zsh", "bash", "sh"}
_EVAL = " eval '"
_CWD_MARK = "pwd -P >| "


@dataclass(frozen=True)
class ShellCmd:
    command: str      # 还原后的命令原文，与 tool_use.input.command 一致
    stdin_open: bool  # 没有 "< /dev/null"（命令含 heredoc 时），交互提示会阻塞


def parse_shell_cmdline(argv) -> ShellCmd | None:
    """识别 `zsh -c "source <快照> && … && eval '<命令>' [< /dev/null] && pwd -P >| …"`。

    eval 参数里的单引号被写成 '"'"'，这里按 shell 相邻引号拼接的规则还原。
    """
    if len(argv) < 3 or os.path.basename(argv[0]) not in SHELLS or argv[1] != "-c":
        return None
    script = argv[2]
    i = script.find(_EVAL)
    if i < 0 or _CWD_MARK not in script:
        return None
    i += len(_EVAL) - 1
    parts = []
    while i < len(script):
        if script[i] == "'":
            j = script.find("'", i + 1)
            if j < 0:
                return None
            parts.append(script[i + 1:j])
            i = j + 1
        elif script.startswith("\"'\"", i):
            parts.append("'")
            i += 3
        else:
            break
    rest = script[i:].lstrip()
    return ShellCmd("".join(parts), not rest.startswith("< /dev/null"))


# ---------- 命令里的 L= 日志路径 ----------

_ASSIGN_RE = re.compile(
    r"""(?:^|[;&|\s(])([A-Za-z_]\w*)=(?:"([^"\n]*)"|'([^'\n]*)'|([^\s;&|'"`()]*))""", re.MULTILINE)
_VAR_RE = re.compile(r"\$\{(\w+)\}|\$(\w+)")
_UNKNOWN = "\0"


def is_log_candidate(path: str) -> bool:
    """已存在的目录或可执行文件不是日志（如 L=/usr/bin/log）；不存在的路径视为稍后才创建的日志。"""
    try:
        st = os.stat(path)
    except OSError:
        return True
    return not stat.S_ISDIR(st.st_mode) and not st.st_mode & 0o111


def extract_log_path(command: str) -> str | None:
    """找出命令里第一个可用的 `L=<绝对路径>`。

    支持引用同一条命令里先前的简单赋值（`S=/tmp/x; L=$S/a.log`），其余变量取当前环境；
    展开不了的（`L=$(...)`、未知变量）一律放弃。
    """
    env: dict[str, str] = {}

    def expand(v: re.Match) -> str:
        name = v.group(1) or v.group(2)
        return env.get(name, os.environ.get(name, _UNKNOWN))

    for m in _ASSIGN_RE.finditer(command):
        name, dq, sq, bare = m.groups()
        if sq is not None:
            val = sq
        else:
            val = _VAR_RE.sub(expand, dq if dq is not None else bare)
        if name == "L":
            if (val.startswith("/") and _UNKNOWN not in val and "$" not in val and "`" not in val
                    and is_log_candidate(val)):
                return val
            continue
        env[name] = val
    return None


# ---------- 会话 jsonl ----------

@dataclass(frozen=True)
class ToolUse:
    id: str
    ts: float
    command: str
    description: str
    timeout_ms: int | None
    background: bool


@dataclass(frozen=True)
class ToolResult:
    tool_use_id: str
    ts: float
    is_error: bool
    exit_code: int | None        # None：后台命令的启动回执
    bg_output: str | None        # 后台命令的输出文件
    denied: tuple[str, ...]      # 被 EOF 自动拒绝的 -i 提示


@dataclass(frozen=True)
class TaskDone:
    """后台命令结束的通知（queue-operation 里的 <task-notification>）。"""
    tool_use_id: str
    ts: float
    status: str
    exit_code: int


_EXIT_RE = re.compile(r"^Exit code (\d+)")
_BG_RE = re.compile(r"Output is being written to: (/\S+?\.output)")
_DENIED_RES = (
    re.compile(r"(?m)^(?:rm: )?remove [^\n]*?\?(?= |$)"),
    re.compile(r"(?m)^(?:(?:cp|mv): )?overwrite [^\n]*?\?(?: \(y/n \[n\]\) not overwritten)?"),
)
_TN_ID = re.compile(r"<tool-use-id>([^<]+)</tool-use-id>")
_TN_STATUS = re.compile(r"<status>([^<]+)</status>")
_TN_EXIT = re.compile(r"exit code (\d+)")     # "completed (exit code 0)" / "failed with exit code 144"
_TN_FINAL = {"completed", "failed", "killed", "stopped"}


def parse_result(tool_use_id: str, ts: float, text: str, is_error: bool) -> ToolResult:
    bg = _BG_RE.search(text)
    m = _EXIT_RE.match(text)
    if bg:
        code = None
    elif m:
        code = int(m.group(1))
    else:
        code = 1 if is_error else 0
    denied = tuple(x.group(0) for r in _DENIED_RES for x in r.finditer(text))
    return ToolResult(tool_use_id, ts, is_error, code, bg.group(1) if bg else None, denied)


def parse_task_notification(text: str, ts: float) -> TaskDone | None:
    """只认终止状态（completed/failed/killed/stopped）；running 等中间状态返回 None。"""
    m = _TN_ID.search(text)
    st = _TN_STATUS.search(text)
    if "<task-notification>" not in text or not m or not st or st.group(1) not in _TN_FINAL:
        return None
    ex = _TN_EXIT.search(text)
    code = int(ex.group(1)) if ex else (0 if st.group(1) == "completed" else 1)
    return TaskDone(m.group(1), ts, st.group(1), code)


def _ts(s) -> float:
    try:
        return datetime.fromisoformat(str(s).replace("Z", "+00:00")).timestamp()
    except ValueError:
        return 0.0


def _text(content) -> str:
    if isinstance(content, str):
        return content
    if isinstance(content, list):
        return "\n".join(b.get("text", "") for b in content if isinstance(b, dict))
    return ""


def parse_record(d: dict) -> list:
    """一条 jsonl 记录 → [ToolUse | ToolResult | TaskDone]；只取 Bash 的 tool_use。"""
    ts = _ts(d.get("timestamp"))
    if d.get("type") == "queue-operation" and d.get("operation") == "enqueue":
        td = parse_task_notification(d.get("content") or "", ts) if isinstance(d.get("content"), str) else None
        return [td] if td else []
    msg = d.get("message")
    if not isinstance(msg, dict) or not isinstance(msg.get("content"), list):
        return []
    out: list = []
    for b in msg["content"]:
        if not isinstance(b, dict):
            continue
        if b.get("type") == "tool_use" and b.get("name") == "Bash":
            inp = b.get("input") or {}
            if not isinstance(inp.get("command"), str):
                continue
            timeout = inp.get("timeout")
            out.append(ToolUse(str(b.get("id")), ts, inp["command"], str(inp.get("description") or ""),
                               int(timeout) if isinstance(timeout, (int, float)) else None,
                               bool(inp.get("run_in_background"))))
        elif b.get("type") == "tool_result":
            out.append(parse_result(str(b.get("tool_use_id")), ts, _text(b.get("content")), bool(b.get("is_error"))))
    return out


class JsonlTail:
    """按偏移增量读取 jsonl；逐行先做子串预检，命中才 json 解析。文件被替换或截断时从头读。"""

    PREFILTER = (b'"tool_use"', b'"tool_result"', b"<task-notification>")

    def __init__(self, path: Path):
        self.path = path
        self.offset = 0
        self._buf = b""
        self._ino: int | None = None

    def poll(self) -> list[dict]:
        try:
            st = self.path.stat()
        except OSError:
            return []
        if st.st_ino != self._ino or st.st_size < self.offset:
            self.offset, self._buf, self._ino = 0, b"", st.st_ino
        if st.st_size == self.offset:
            return []
        with self.path.open("rb") as f:
            f.seek(self.offset)
            data = f.read()
        self.offset += len(data)
        lines = (self._buf + data).split(b"\n")
        self._buf = lines.pop()
        out = []
        for raw in lines:
            if not any(k in raw for k in self.PREFILTER):
                continue
            try:
                out.append(json.loads(raw))
            except ValueError:
                continue
        return out


def find_transcripts(projects_dir: Path, session_id: str) -> list[Path]:
    """主会话 jsonl 与其 subagent jsonl。"""
    main = sorted(projects_dir.glob(f"*/{session_id}.jsonl"))
    subs = sorted(projects_dir.glob(f"*/{session_id}/subagents/*.jsonl"))
    return main + subs


# ---------- 日志文件 ----------

def read_tail(path: str, max_bytes: int = 65536) -> tuple[list[str], int]:
    """读日志末尾 max_bytes，返回（完整行列表, 当前文件大小）。从中间开始时丢掉第一行残行。"""
    try:
        with open(path, "rb") as f:
            size = f.seek(0, os.SEEK_END)
            start = max(0, size - max_bytes)
            f.seek(start)
            data = f.read(size - start)
    except OSError:
        return [], 0
    text = data.decode("utf-8", errors="replace")
    lines = text.split("\n")
    if start > 0:
        lines = lines[1:]
    if lines and lines[-1] == "":
        lines.pop()
    return [_last_cr(x) for x in lines], size


def _last_cr(line: str) -> str:
    """进度条用 \\r 覆盖同一行，只保留最后一段。"""
    return line.rstrip("\r").rsplit("\r", 1)[-1]


class LineFollower:
    """从 offset 起跟随日志新增的完整行；文件被截断（重新写 > $L）时从头读。"""

    def __init__(self, path: str, offset: int = 0):
        self.path = path
        self.offset = offset
        self._buf = b""

    def poll(self) -> list[str]:
        try:
            with open(self.path, "rb") as f:
                size = f.seek(0, os.SEEK_END)
                if size < self.offset:
                    self.offset, self._buf = 0, b""
                f.seek(self.offset)
                data = f.read(size - self.offset)
        except OSError:
            return []
        self.offset += len(data)
        parts = (self._buf + data).split(b"\n")
        self._buf = parts.pop()
        return [_last_cr(p.decode("utf-8", errors="replace")) for p in parts]
```

```python
"""状态判定：纯函数，输入命令的进程树与活动记录，输出状态；另含通知去重。"""

import os
from collections.abc import Sequence
from dataclasses import dataclass
from enum import Enum

from cctail.procs import ProcInfo

BG_ICON = "⏳"
CPU_EPS = 0.02   # 进程树累计 CPU 增长超过该秒数才算「在干活」

INTERACTIVE_CMDS = frozenset({"rm", "cp", "mv", "ln", "grm", "gcp", "gmv", "gln"})
AUTH_NAMES = frozenset({"pinentry", "pinentry-mac", "pinentry-curses", "pinentry-tty", "ssh-askpass",
                        "osascript", "security", "codesign", "sudo", "su", "passwd", "login"})
WAIT_NAMES = frozenset({"sleep", "gsleep"})


class State(Enum):
    CONFIRM = ("🔴", "等待确认", True)
    AUTH = ("🔴", "等待授权", True)
    LISTEN = ("🔵", "监听中", True)
    HUNG = ("🟠", "疑似卡死", True)
    QUIET = ("🟡", "安静工作", False)
    RUNNING = ("🟢", "运行中", False)
    DONE_OK = ("✅", "成功结束", False)
    DONE_FAIL = ("❌", "失败结束", False)
    DENIED = ("🚫", "-i 被自动拒绝", False)

    def __init__(self, icon: str, label: str, alert: bool):
        self.icon = icon
        self.label = label
        self.alert = alert

    @property
    def ended(self) -> bool:
        return self in (State.DONE_OK, State.DONE_FAIL, State.DENIED)


@dataclass(frozen=True)
class Thresholds:
    confirm: float = 3
    gui: float = 5
    listen: float = 10
    hung_fg: float = 30
    hung_bg: float = 300
    quiet: float = 3        # 输出停止增长多久后从 🟢 变 🟡
    keep_done: float = 600


@dataclass
class Activity:
    """输出量与 CPU 最近一次增长的时间；首次采样时两者都记为首次采样时间。"""
    out: int
    cpu: float
    out_at: float
    cpu_at: float

    @classmethod
    def start(cls, t: float, out: int, cpu: float) -> "Activity":
        return cls(out, cpu, t, t)

    def update(self, t: float, out: int, cpu: float) -> None:
        if out > self.out:
            self.out_at = t
        self.out = out
        if cpu < self.cpu:                 # 子进程退出导致总和变小：只重置基线
            self.cpu = cpu
        elif cpu - self.cpu > CPU_EPS:     # 基线只在确认增长时前移，慢速累积也能被发现
            self.cpu, self.cpu_at = cpu, t


@dataclass(frozen=True)
class Verdict:
    state: State
    proc: ProcInfo | None = None      # 导致告警的进程


def cmd_name(p: ProcInfo) -> str:
    """优先用 argv[0] 的 basename：macOS 的 /bin/sh 进程名是 bash。"""
    return os.path.basename(p.argv[0]) if p.argv else p.name


def has_interactive_flag(argv: Sequence[str]) -> bool:
    for a in argv[1:]:
        if a == "--":
            break
        if a == "--interactive" or (a.startswith("--interactive=") and a != "--interactive=never"):
            return True
        if a.startswith("-") and not a.startswith("--") and ("i" in a[1:] or "I" in a[1:]):
            return True
    return False


def _leaf(tree: Sequence[ProcInfo]) -> ProcInfo | None:
    parents = {p.ppid for p in tree}
    leaves = [p for p in tree if p.pid not in parents]
    return leaves[-1] if leaves else (tree[-1] if tree else None)


def classify(*, now: float, ended: bool, exit_code: int | None, denied: Sequence[str], background: bool,
             stdin_open: bool, tree: Sequence[ProcInfo], act: Activity | None, th: Thresholds,
             auth_names: frozenset[str] = AUTH_NAMES) -> Verdict:
    if ended:
        if denied:
            return Verdict(State.DENIED)
        if exit_code not in (None, 0):
            return Verdict(State.DONE_FAIL)
        return Verdict(State.DONE_OK)
    if act is None:
        return Verdict(State.RUNNING)
    out_idle, cpu_idle = now - act.out_at, now - act.cpu_at
    for p in tree:
        if stdin_open and cmd_name(p) in INTERACTIVE_CMDS and has_interactive_flag(p.argv) and cpu_idle >= th.confirm:
            return Verdict(State.CONFIRM, p)
    for p in tree:
        n = cmd_name(p)
        if (n in auth_names or n.startswith("pinentry")) and cpu_idle >= th.gui:
            return Verdict(State.AUTH, p)
    for p in tree:
        if p.listening and out_idle >= th.listen:
            return Verdict(State.LISTEN, p)
    hung = th.hung_bg if background else th.hung_fg
    if out_idle >= hung and cpu_idle >= hung and not any(cmd_name(p) in WAIT_NAMES for p in tree):
        return Verdict(State.HUNG, _leaf(tree))
    if out_idle < th.quiet:
        return Verdict(State.RUNNING)
    return Verdict(State.QUIET)


def should_alert(state: State, background: bool) -> bool:
    """后台命令监听端口是预期行为（dev server），不告警。"""
    return state.alert and not (state is State.LISTEN and background)


class Alerter:
    """每条命令每进入一个告警状态只通知一次；离开告警状态后再次进入会重新通知。"""

    def __init__(self):
        self._last: dict[str, State] = {}

    def check(self, key: str, state: State, background: bool) -> bool:
        if not should_alert(state, background):
            self._last.pop(key, None)
            return False
        if self._last.get(key) is state:
            return False
        self._last[key] = state
        return True

    def rekey(self, old: str, new: str) -> None:
        if old in self._last:
            self._last[new] = self._last.pop(old)

    def forget(self, key: str) -> None:
        self._last.pop(key, None)
```

```python
"""汇总各数据源：每个 tick 读会话、jsonl 与进程树，维护正在执行 / 刚结束的 Bash 命令。

命令的来源有两个：
- 进程：claude 进程下的 `zsh -c … eval '<命令>'` 子进程，即正在执行的命令；
- jsonl：已有 tool_result 却从没见过进程的命令（执行得太快），直接作为已结束命令出现。
进程与 tool_use 按「同会话 + 命令原文相同」配对；配对前命令以 pid:<pid> 为键，配对后改用 tool_use id。
"""

import os
import time
from collections.abc import Callable, Sequence
from dataclasses import dataclass, field
from pathlib import Path
from typing import Literal

from cctail.detect import AUTH_NAMES, Activity, Alerter, State, Thresholds, Verdict, classify, should_alert
from cctail.procs import ProcInfo, ProcProvider
from cctail.sources import (
    JsonlTail,
    SessionInfo,
    TaskDone,
    ToolResult,
    ToolUse,
    extract_log_path,
    find_transcripts,
    parse_record,
    parse_shell_cmdline,
    read_sessions,
)

DEFAULT_TIMEOUT_MS = 120_000
BIND_SLACK = 30      # tool_use 最多比首次看到进程早这么多秒，防止配到很久以前同文本的命令
END_GRACE = 3        # 进程消失后最多等这么久的 tool_result / 任务通知，再发「结束」事件


@dataclass
class Command:
    key: str
    session: SessionInfo
    text: str
    started_at: float
    description: str = ""
    timeout_ms: int | None = None
    background: bool = False
    tool_use_id: str | None = None
    pid: int | None = None
    stdin_open: bool = False
    tree: list[ProcInfo] = field(default_factory=list)
    log_path: str | None = None
    log_source: str | None = None         # "L=" | "background"
    log_size: int = 0
    exit_code: int | None = None
    denied: tuple[str, ...] = ()
    ended_at: float | None = None
    act: Activity | None = None
    verdict: Verdict = field(default_factory=lambda: Verdict(State.RUNNING))

    @property
    def running(self) -> bool:
        return self.ended_at is None

    @property
    def title(self) -> str:
        """优先 description，否则命令原文的第一个非空行。"""
        return self.description or next((x.strip() for x in self.text.splitlines() if x.strip()), "")

    def timeout_left(self, now: float) -> float | None:
        if self.background or not self.running:
            return None
        return (self.timeout_ms or DEFAULT_TIMEOUT_MS) / 1000 - (now - self.started_at)


@dataclass(frozen=True)
class Event:
    kind: Literal["start", "alert", "end"]
    cmd: Command
    verdict: Verdict


def _size(path: str | None) -> int:
    if not path:
        return 0
    try:
        return os.stat(path).st_size
    except OSError:
        return 0


class Tracker:
    def __init__(self, procs: ProcProvider, *, claude_dir: Path | None = None,
                 clock: Callable[[], float] = time.time, sessions_filter: Sequence[str] = (),
                 th: Thresholds | None = None, auth_names: frozenset[str] = AUTH_NAMES):
        self._procs = procs
        self._dir = claude_dir or Path.home() / ".claude"
        self._clock = clock
        self._filter = list(sessions_filter)
        self.th = th or Thresholds()
        self._auth = auth_names
        self.sessions: list[SessionInfo] = []
        self.commands: dict[str, Command] = {}
        self._pid_key: dict[int, str] = {}
        self._uses: dict[str, tuple[SessionInfo, ToolUse]] = {}
        self._by_text: dict[tuple[str, str], list[str]] = {}
        self._results: dict[str, ToolResult] = {}
        self._task_done: dict[str, TaskDone] = {}
        self._bound: set[str] = set()
        self._tails: dict[Path, JsonlTail] = {}
        self._alerter = Alerter()
        self._pending_end: set[str] = set()
        self._primed = False

    # ---------- 对外 ----------

    def tick(self) -> list[Event]:
        now = self._clock()
        events: list[Event] = []
        self.sessions = [s for s in read_sessions(self._dir / "sessions")
                         if self._wanted(s) and self._procs.alive(s.pid)]
        for s in self.sessions:
            self._ingest(s)
        live = self._scan_processes(now, events)
        for cmd in list(self.commands.values()):
            if cmd.running and cmd.tool_use_id is None:
                self._bind(cmd)
        self._finish(now, live)
        self._from_results()
        self._evaluate(now, events)
        self._expire(now)
        self._primed = True
        return events

    def ordered(self, show_done: bool = True) -> list[Command]:
        """告警中 > 运行中（新的在前）> 已结束（新结束的在前）。"""
        def rank(c: Command):
            if c.running and should_alert(c.verdict.state, c.background):
                return (0, -c.started_at)
            if c.running:
                return (1, -c.started_at)
            return (2, -(c.ended_at or 0))
        return sorted((c for c in self.commands.values() if show_done or c.running), key=rank)

    # ---------- 数据源 ----------

    def _wanted(self, s: SessionInfo) -> bool:
        return not self._filter or any(f in s.name or f in s.session_id for f in self._filter)

    def _ingest(self, s: SessionInfo) -> None:
        for path in find_transcripts(self._dir / "projects", s.session_id):
            tail = self._tails.setdefault(path, JsonlTail(path))
            for rec in tail.poll():
                for item in parse_record(rec):
                    if isinstance(item, ToolUse):
                        if item.id not in self._uses:
                            self._uses[item.id] = (s, item)
                            self._by_text.setdefault((s.session_id, item.command), []).append(item.id)
                    elif isinstance(item, ToolResult):
                        if item.tool_use_id in self._uses:
                            self._results[item.tool_use_id] = item
                    elif isinstance(item, TaskDone):
                        self._task_done[item.tool_use_id] = item

    def _scan_processes(self, now: float, events: list[Event]) -> set[int]:
        live: set[int] = set()
        for s in self.sessions:
            for child in self._procs.children(s.pid):
                sc = parse_shell_cmdline(child.argv)
                if sc is None:
                    continue
                live.add(child.pid)
                key = self._pid_key.get(child.pid)
                cmd = self.commands.get(key) if key else None
                if cmd is None:
                    cmd = Command(key=f"pid:{child.pid}", session=s, text=sc.command, started_at=now,
                                  pid=child.pid, stdin_open=sc.stdin_open)
                    lp = extract_log_path(sc.command)
                    if lp:
                        cmd.log_path, cmd.log_source = lp, "L="
                    self.commands[cmd.key] = cmd
                    self._pid_key[child.pid] = cmd.key
                    self._bind(cmd)
                    if self._primed:
                        events.append(Event("start", cmd, cmd.verdict))
                cmd.tree = self._procs.tree(child.pid)
        return live

    def _bind(self, cmd: Command) -> None:
        """为进程找对应的 tool_use：同会话、原文相同、未被占用、时间不早于首次看到进程前 BIND_SLACK 秒。"""
        ids = self._by_text.get((cmd.session.session_id, cmd.text), [])
        cands = [self._uses[i][1] for i in ids
                 if i not in self._bound and self._uses[i][1].ts >= cmd.started_at - BIND_SLACK]
        if not cands:
            return
        u = min(cands, key=lambda x: x.ts)
        self._bound.add(u.id)
        old = cmd.key
        del self.commands[old]
        cmd.key = cmd.tool_use_id = u.id
        cmd.description, cmd.timeout_ms, cmd.background = u.description, u.timeout_ms, u.background
        cmd.started_at = min(cmd.started_at, u.ts)
        self.commands[cmd.key] = cmd
        if cmd.pid is not None:
            self._pid_key[cmd.pid] = cmd.key
        self._alerter.rekey(old, cmd.key)

    def _finish(self, now: float, live: set[int]) -> None:
        for cmd in self.commands.values():
            if cmd.running and cmd.pid is not None and cmd.pid not in live:
                cmd.ended_at, cmd.tree = now, []
                self._pending_end.add(cmd.key)

    def _from_results(self) -> None:
        """有结果却没见过进程的命令（执行太快）：直接作为已结束命令加入。后台命令等任务通知。"""
        horizon = self._clock() - self.th.keep_done
        for uid, r in self._results.items():
            if uid in self._bound:
                continue
            s, u = self._uses[uid]
            td = self._task_done.get(uid)
            if u.background and td is None:
                continue
            ended = td.ts if (u.background and td) else r.ts
            if ended < horizon:
                continue
            self._bound.add(uid)
            cmd = Command(key=uid, session=s, text=u.command, started_at=u.ts, description=u.description,
                          timeout_ms=u.timeout_ms, background=u.background, tool_use_id=uid, ended_at=ended)
            lp = extract_log_path(u.command)
            if lp:
                cmd.log_path, cmd.log_source = lp, "L="
            self.commands[uid] = cmd
            self._pending_end.add(uid)

    # ---------- 判定 ----------

    def _evaluate(self, now: float, events: list[Event]) -> None:
        for cmd in self.commands.values():
            r = self._results.get(cmd.tool_use_id) if cmd.tool_use_id else None
            td = self._task_done.get(cmd.tool_use_id) if cmd.tool_use_id else None
            if r and r.bg_output and cmd.log_source is None:
                cmd.log_path, cmd.log_source = r.bg_output, "background"
            if cmd.background:
                if td:
                    cmd.exit_code = td.exit_code
            elif r:
                cmd.exit_code, cmd.denied = r.exit_code, r.denied
            cmd.log_size = _size(cmd.log_path)
            if cmd.running:
                cpu = sum(p.cpu for p in cmd.tree)
                if cmd.act is None:
                    cmd.act = Activity.start(now, cmd.log_size, cpu)
                else:
                    cmd.act.update(now, cmd.log_size, cpu)
            v = classify(now=now, ended=not cmd.running, exit_code=cmd.exit_code, denied=cmd.denied,
                         background=cmd.background, stdin_open=cmd.stdin_open, tree=cmd.tree, act=cmd.act,
                         th=self.th, auth_names=self._auth)
            cmd.verdict = v
            if self._alerter.check(cmd.key, v.state, cmd.background):
                events.append(Event("alert", cmd, v))
            if cmd.key in self._pending_end:
                known = td is not None if cmd.background else r is not None
                if known or now - (cmd.ended_at or now) >= END_GRACE:
                    self._pending_end.discard(cmd.key)
                    if self._primed:
                        events.append(Event("end", cmd, v))

    def _expire(self, now: float) -> None:
        for key, cmd in list(self.commands.items()):
            if not cmd.running and now - (cmd.ended_at or now) > self.th.keep_done:
                del self.commands[key]
                self._alerter.forget(key)
                self._pending_end.discard(key)
                if cmd.pid is not None and self._pid_key.get(cmd.pid) == key:
                    del self._pid_key[cmd.pid]
```

```python
"""仪表盘与流式模式共用的格式化：时长、大小、告警文案、时长参数解析。"""

import re

from cctail.model import Command


def fmt_duration(sec: float | None) -> str:
    """m:ss，超过一小时 h:mm:ss；None 或负数显示 -。"""
    if sec is None or sec < 0:
        return "-"
    s = int(sec)
    h, rem = divmod(s, 3600)
    m, s = divmod(rem, 60)
    return f"{h}:{m:02d}:{s:02d}" if h else f"{m}:{s:02d}"


def fmt_size(n: int) -> str:
    """最多 5 列：1023、9.9K、123K、1.2M。"""
    if n < 1024:
        return str(n)
    x = float(n)
    for unit in ("K", "M", "G"):
        x /= 1024
        if x < 1024 or unit == "G":
            return f"{x:.1f}{unit}" if x < 10 else f"{x:.0f}{unit}"
    return str(n)


def fmt_idle(sec: float | None) -> str:
    if sec is None:
        return "-"
    s = int(sec)
    return f"{s}s" if s < 100 else f"{s // 60}m" if s < 6000 else f"{s // 3600}h"


def parse_duration(text: str) -> float:
    """600、90s、10m、1h → 秒。"""
    m = re.fullmatch(r"\s*(\d+(?:\.\d+)?)\s*([smh]?)\s*", text)
    if not m:
        raise ValueError(f"无法解析时长：{text!r}")
    return float(m.group(1)) * {"": 1, "s": 1, "m": 60, "h": 3600}[m.group(2)]


def alert_detail(cmd: Command, now: float) -> str:
    """告警细节：导致告警的进程与超时剩余；都没有时为空串。"""
    parts = []
    p = cmd.verdict.proc
    if p is not None:
        parts.append(f"{' '.join(p.argv)[:80]} (pid {p.pid})")
    left = cmd.timeout_left(now)
    if left is not None:
        parts.append(f"超时剩余 {fmt_duration(left)}")
    return "；".join(parts)


def alert_text(cmd: Command, now: float) -> tuple[str, str]:
    """（标题, 正文），用于桌面通知。"""
    v = cmd.verdict
    detail = alert_detail(cmd, now)
    body = f"{cmd.session.name} · {cmd.title}" + (f"；{detail}" if detail else "")
    return f"cc-tail {v.state.icon} {v.state.label}", body
```

```python
"""桌面通知：默认向终端写 OSC 9 + BEL（Ghostty、cmux、iTerm2 支持），不启动外部程序；
可选 osascript（系统通知中心），或关闭。

只发 OSC 9 不发 OSC 777：两者都支持的终端（如 Ghostty）会弹两次。
"""

import subprocess
from collections.abc import Callable

MODES = ("osc", "osascript", "none")
BEL = "\a"


def _clean(s: str) -> str:
    return "".join(ch for ch in s if ch >= " " and ch != "\x7f")


def osc9(title: str, body: str) -> str:
    return f"\x1b]9;{_clean(f'{title}: {body}')}\a"


def applescript(title: str, body: str) -> str:
    def q(s: str) -> str:
        return '"' + _clean(s).replace("\\", "\\\\").replace('"', '\\"') + '"'
    return f"display notification {q(body)} with title {q(title)}"


class Notifier:
    def __init__(self, mode: str, write: Callable[[str], None] | None):
        if mode not in MODES:
            raise ValueError(f"未知通知方式：{mode}（可选 {', '.join(MODES)}）")
        self.mode = mode
        self._write = write

    def send(self, title: str, body: str) -> None:
        if self.mode == "none":
            return
        if self.mode == "osc":
            if self._write:
                self._write(osc9(title, body) + BEL)
            return
        subprocess.Popen(["osascript", "-e", applescript(title, body)],
                         stdout=subprocess.DEVNULL, stderr=subprocess.DEVNULL)
        if self._write:
            self._write(BEL)
```

```python
"""流式模式：合并输出各命令日志的新增行，状态变化单独插入醒目的一行。"""

import time
import zlib

from rich.console import Console
from rich.text import Text

from cctail.cells import fit
from cctail.detect import BG_ICON
from cctail.fmt import alert_detail, alert_text, fmt_duration
from cctail.model import Command, Event, Tracker
from cctail.notify import Notifier
from cctail.sources import LineFollower, read_tail

PALETTE = ("cyan", "magenta", "green", "yellow", "blue", "bright_cyan", "bright_magenta", "bright_green")


class StreamPrinter:
    def __init__(self, console: Console, *, prefix_width: int = 36, backlog: int = 10,
                 clock=time.time):
        self.console = console
        self.prefix_width = prefix_width
        self.backlog = backlog
        self._clock = clock
        self._followers: dict[int, LineFollower] = {}     # id(Command) → 跟随器（rekey 后对象不变）

    def prefix(self, cmd: Command) -> Text:
        bg = f"{BG_ICON} " if cmd.background else ""
        label = fit(f"{bg}{cmd.session.name} · {cmd.title}", self.prefix_width)
        color = PALETTE[zlib.crc32(str(id(cmd)).encode()) % len(PALETTE)]   # 配对改键后对象不变，颜色也不变
        return Text(f"[{label}]", style=color)

    def _stamp(self) -> Text:
        return Text(time.strftime("%H:%M:%S ", time.localtime(self._clock())), style="dim")

    def _line(self, *parts: Text | str) -> None:
        t = self._stamp()
        for p in parts:
            t.append_text(p if isinstance(p, Text) else Text(p))
        self.console.print(t, soft_wrap=True, highlight=False, markup=False)

    def handle(self, commands: list[Command], events: list[Event]) -> None:
        """先打印「开始」，再打印各命令日志新增行，最后打印告警与「结束」。"""
        now = self._clock()
        for ev in events:
            if ev.kind == "start":
                self._line(f"{ev.verdict.state.icon} ", self.prefix(ev.cmd), " 开始")
        for cmd in commands:
            self._print_log(cmd)
        for ev in events:
            v = ev.verdict
            if ev.kind == "alert":
                self._line(Text(f"!!! {v.state.icon} {v.state.label} ", style="bold red"), self.prefix(ev.cmd),
                           Text(" " + alert_detail(ev.cmd, now), style="bold red"))
            elif ev.kind == "end":
                code = "-" if ev.cmd.exit_code is None else str(ev.cmd.exit_code)
                used = fmt_duration((ev.cmd.ended_at or now) - ev.cmd.started_at)
                self._line(f"{v.state.icon} ", self.prefix(ev.cmd), f" 退出码 {code}，用时 {used}")
        live = {id(c) for c in commands}
        for k in [k for k in self._followers if k not in live]:
            del self._followers[k]

    def _print_log(self, cmd: Command) -> None:
        if not cmd.log_path:
            return
        f = self._followers.get(id(cmd))
        if f is None or f.path != cmd.log_path:
            lines, size = read_tail(cmd.log_path)
            self._followers[id(cmd)] = LineFollower(cmd.log_path, size)
            lines = lines[-self.backlog:] if cmd.running else []
        else:
            lines = f.poll()
        for line in lines:
            self._line(self.prefix(cmd), " ", Text.from_ansi(line))


def run_stream(tracker: Tracker, notifier: Notifier, console: Console | None = None,
               interval: float = 1.0) -> int:
    console = console or Console(highlight=False)
    printer = StreamPrinter(console)
    try:
        while True:
            events = tracker.tick()
            printer.handle(tracker.ordered(), events)
            for ev in events:
                if ev.kind == "alert":
                    notifier.send(*alert_text(ev.cmd, time.time()))
            time.sleep(interval)
    except KeyboardInterrupt:
        return 0
```

```python
"""仪表盘：上半部分是命令表，下半部分是选中命令的 日志 / 进程树 / 命令 三个页签。

光标由 App 自己管理（↑↓/jk 为高优先级绑定）：每个 tick 会重建表格，DataTable 自身的
高亮事件分不清是用户还是程序触发，因此不依赖它。
"""

import time
from typing import ClassVar

from rich.text import Text
from textual import events
from textual.app import App, ComposeResult
from textual.binding import Binding
from textual.widgets import DataTable, Footer, RichLog, Static, TabbedContent, TabPane

from cctail.cells import fit
from cctail.detect import BG_ICON, should_alert
from cctail.fmt import alert_text, fmt_duration, fmt_idle, fmt_size
from cctail.model import Command, Event, Tracker
from cctail.notify import Notifier
from cctail.sources import LineFollower, read_tail

# (key, 表头, 宽度, 对齐)；宽度 None 的「命令」列占用剩余宽度
COLUMNS = [("state", "状态", 4, "left"), ("bg", "后台", 4, "left"), ("session", "会话", 16, "left"),
           ("cmd", "命令", None, "left"), ("run", "运行", 7, "right"), ("left", "超时", 7, "right"),
           ("out", "输出", 5, "right"), ("idle", "静默", 4, "right")]
MIN_CMD_WIDTH = 12
TABS = ("tab-log", "tab-tree", "tab-cmd")


def cmd_col_width(total: int) -> int:
    fixed = sum(w for _, _, w, _ in COLUMNS if w)
    return max(MIN_CMD_WIDTH, total - fixed - 2 * len(COLUMNS) - 2)   # 每列左右各 1 格内边距，另留滚动条


def row_cells(c: Command, now: float, cmd_width: int) -> list[Text]:
    idle = now - c.act.out_at if (c.running and c.act) else None
    vals = [c.verdict.state.icon, BG_ICON if c.background else "", c.session.name, c.title,
            fmt_duration((c.ended_at or now) - c.started_at) if c.running else "-",
            fmt_duration(c.timeout_left(now)), fmt_size(c.log_size) if c.log_path else "-", fmt_idle(idle)]
    return [Text(fit(v, w or cmd_width, align)) for v, (_, _, w, align) in zip(vals, COLUMNS)]


def render_tree(c: Command) -> Text:
    if not c.tree:
        return Text("进程已结束" if not c.running else "（暂无进程信息）")
    depth: dict[int, int] = {}
    hot = c.verdict.proc.pid if c.verdict.proc else None
    t = Text()
    for p in c.tree:
        d = depth[p.pid] = depth.get(p.ppid, -1) + 1
        line = (f"{p.pid:>7} {p.status:<9} {p.cpu:>8.2f}s {'LISTEN' if p.listening else '':<6} "
                f"{'  ' * d}{' '.join(p.argv)}")
        t.append(line[:500] + "\n", style="bold red" if p.pid == hot else "")
    return t


def render_cmd(c: Command) -> Text:
    t = Text()
    t.append(f"会话：{c.session.name}（{c.session.session_id}）\n", style="bold")
    if c.description:
        t.append(f"说明：{c.description}\n")
    t.append(f"日志：{c.log_path or '（无）'}\n")
    if c.pid:
        t.append(f"进程：{c.pid}\n")
    t.append("\n" + c.text)
    return t


class CcTailApp(App):
    CSS = """
    #title { height: 1; background: $panel; }
    #cmds { height: 1fr; }
    #detail { height: 1fr; }
    """
    BINDINGS: ClassVar = [
        Binding("up,k", "cursor(-1)", "选择", show=False, priority=True),
        Binding("down,j", "cursor(1)", "选择", show=False, priority=True),
        Binding("tab", "next_tab", "切换面板", priority=True),
        Binding("f", "follow", "跟随"),
        Binding("a", "toggle_done", "显示已结束"),
        Binding("c", "copy_path", "复制路径"),
        Binding("q", "quit", "退出"),
    ]

    def __init__(self, tracker: Tracker, *, notifier: Notifier | None = None, notify_mode: str = "osc",
                 interval: float = 1.0, clock=time.time):
        super().__init__()
        self.tracker = tracker
        self.notifier = notifier or Notifier(notify_mode, self._term_write)
        self._interval = interval
        self._clock = clock
        self.follow = True
        self.show_done = True
        self._cmds: list[Command] = []
        self._sel: Command | None = None
        self._log_key: tuple[int, str | None] | None = None
        self._follower: LineFollower | None = None
        self._busy = False
        self._columns_ready = False
        self._width = 0

    def _term_write(self, s: str) -> None:
        if self._driver is not None and not self.is_headless:
            self._driver.write(s)

    def compose(self) -> ComposeResult:
        yield Static(id="title")
        yield DataTable(id="cmds", cursor_type="row")
        with TabbedContent(id="detail"):
            with TabPane("日志", id="tab-log"):
                yield RichLog(id="log", max_lines=5000, wrap=False, markup=False, highlight=False)
            with TabPane("进程树", id="tab-tree"):
                yield Static(id="tree")
            with TabPane("命令", id="tab-cmd"):
                yield Static(id="cmd")
        yield Footer()

    def on_mount(self) -> None:
        self._columns_ready = True
        self._build_columns()
        self.tick_once()
        self.set_interval(self._interval, self._schedule_tick)

    def on_resize(self, event: events.Resize) -> None:
        # 触发时 self.size 还是旧值，以事件里的尺寸为准
        self._width = event.size.width
        if self._columns_ready:
            self._build_columns()
            self._render(self._clock())

    # ---------- tick ----------

    def _schedule_tick(self) -> None:
        if not self._busy:
            self._busy = True
            self.run_worker(self._tick_worker, thread=True, group="tick")

    def _tick_worker(self) -> None:
        try:
            events = self.tracker.tick()
            self.call_from_thread(self._apply, events)
        finally:
            self._busy = False

    def tick_once(self) -> None:
        """同步 tick 一次（首屏与测试用）。"""
        self._apply(self.tracker.tick())

    def _apply(self, events: list[Event]) -> None:
        now = self._clock()
        for ev in events:
            if ev.kind == "alert":
                title, body = alert_text(ev.cmd, now)
                self.notify(body, title=title, severity="error", timeout=15, markup=False)
                self.notifier.send(title, body)
        self._render(now)

    # ---------- 渲染 ----------

    def _cmd_width(self) -> int:
        return cmd_col_width(self._width or self.size.width)

    def _build_columns(self) -> None:
        table = self.query_one("#cmds", DataTable)
        table.clear(columns=True)
        for key, label, w, align in COLUMNS:
            w = w or self._cmd_width()
            table.add_column(Text(fit(label, w, align)), width=w, key=key)

    def _render(self, now: float) -> None:
        self._cmds = self.tracker.ordered(self.show_done)
        if self.follow:
            self._sel = self._follow_target()
        elif self._sel not in self._cmds:
            self._sel = self._cmds[0] if self._cmds else None
        table = self.query_one("#cmds", DataTable)
        cw = self._cmd_width()
        with self.batch_update():
            table.clear()
            for c in self._cmds:
                table.add_row(*row_cells(c, now, cw), key=c.key)
            if self._sel is not None:
                table.move_cursor(row=self._cmds.index(self._sel), animate=False)
        alerts = sum(1 for c in self._cmds if c.running and should_alert(c.verdict.state, c.background))
        running = sum(1 for c in self._cmds if c.running)
        self.query_one("#title", Static).update(Text(
            f" cc-tail - {len(self.tracker.sessions)} 个会话 / {running} 条运行中 / {alerts} 告警"
            f"{' / 跟随中' if self.follow else ''}"))
        self._render_detail()

    def _follow_target(self) -> Command | None:
        for c in self._cmds:
            if c.running and should_alert(c.verdict.state, c.background):
                return c
        return next((c for c in self._cmds if c.running), self._cmds[0] if self._cmds else None)

    def _render_detail(self) -> None:
        c = self._sel
        log = self.query_one("#log", RichLog)
        tabs = self.query_one("#detail", TabbedContent)
        key = (id(c), c.log_path if c else None)
        if key != self._log_key:
            self._log_key = key
            log.clear()
            self._follower = None
            if c is not None and c.log_path:
                lines, size = read_tail(c.log_path)
                for line in lines:
                    log.write(Text.from_ansi(line))
                self._follower = LineFollower(c.log_path, size)
                tabs.active = "tab-log"
            else:
                log.write(Text("无日志文件"))
                tabs.active = "tab-tree"
        elif self._follower is not None:
            for line in self._follower.poll():
                log.write(Text.from_ansi(line))
        self.query_one("#tree", Static).update(render_tree(c) if c else Text(""))
        self.query_one("#cmd", Static).update(render_cmd(c) if c else Text(""))

    # ---------- 按键 ----------

    def action_cursor(self, delta: int) -> None:
        if not self._cmds:
            return
        i = self._cmds.index(self._sel) if self._sel in self._cmds else 0
        self._sel = self._cmds[max(0, min(len(self._cmds) - 1, i + delta))]
        self.follow = False
        self._render(self._clock())

    def action_follow(self) -> None:
        self.follow = True
        self._render(self._clock())

    def action_toggle_done(self) -> None:
        self.show_done = not self.show_done
        self._render(self._clock())

    def action_next_tab(self) -> None:
        tabs = self.query_one("#detail", TabbedContent)
        tabs.active = TABS[(TABS.index(tabs.active) + 1) % len(TABS)]

    def action_copy_path(self) -> None:
        if self._sel is not None and self._sel.log_path:
            self.copy_to_clipboard(self._sel.log_path)
            self.notify(f"已复制：{self._sel.log_path}", markup=False)
```

`package/yyscripts/cc-tail.py`：

```python
#!/usr/bin/env python
"""cc-tail — 跟踪 Claude Code 正在执行的 Bash 命令及其日志，命令卡住时提醒。

数据源（均为 Claude Code 内部格式，2.1.284 实测，官方不保证跨版本稳定）：
  ~/.claude/sessions/<pid>.json          活跃会话
  claude 进程下的 zsh -c … eval '…'       正在执行的命令（psutil，不调用 ps/lsof）
  ~/.claude/projects/*/<session>.jsonl   命令说明、L= 日志、后台输出、退出码

默认进入仪表盘；--stream 改为合并流式输出，便于接 rg。
状态：🔴 等待确认/授权  🔵 监听中  🟠 疑似卡死  🟡 安静工作  🟢 运行中  ✅ ❌ 已结束  🚫 -i 被自动拒绝  ⏳ 后台
阈值（秒）均可用参数或 CC_TAIL_* 环境变量覆盖。设计见 env 仓库 docs/superpowers/specs/2026-09-29-cc-tail-design.md。
"""

import sys
from typing import Annotated

import typer

from cctail.detect import AUTH_NAMES, Thresholds
from cctail.fmt import parse_duration
from cctail.model import Tracker
from cctail.notify import MODES, Notifier
from cctail.procs import PsutilProcs

app = typer.Typer(add_completion=False, context_settings={"help_option_names": ["-h", "--help"]})


def _term_writer():
    """OSC 通知只写给终端：stdout 被管道接走时改用 stderr，都不是终端则不写。"""
    for f in (sys.stdout, sys.stderr):
        if f.isatty():
            return lambda s, f=f: (f.write(s), f.flush())
    return None


@app.command()
def main(
    stream: Annotated[bool, typer.Option("--stream", help="流式输出各命令日志（默认进入仪表盘）")] = False,
    session: Annotated[list[str] | None, typer.Option(
        "--session", "-s", help="只看名字或 ID 包含该片段的会话，可重复")] = None,
    notify: Annotated[str, typer.Option(help=f"通知方式：{'|'.join(MODES)}", envvar="CC_TAIL_NOTIFY")] = "osc",
    confirm_after: Annotated[float, typer.Option(help="🔴 等待确认", envvar="CC_TAIL_CONFIRM_AFTER")] = 3,
    gui_after: Annotated[float, typer.Option(help="🔴 等待授权", envvar="CC_TAIL_GUI_AFTER")] = 5,
    listen_after: Annotated[float, typer.Option(help="🔵 监听中", envvar="CC_TAIL_LISTEN_AFTER")] = 10,
    hung_fg: Annotated[float, typer.Option(help="🟠 疑似卡死（前台）", envvar="CC_TAIL_HUNG_FG")] = 30,
    hung_bg: Annotated[float, typer.Option(help="🟠 疑似卡死（后台）", envvar="CC_TAIL_HUNG_BG")] = 300,
    keep_done: Annotated[str, typer.Option(help="已结束命令保留时长，如 600、90s、10m", envvar="CC_TAIL_KEEP_DONE")] = "10m",
    auth_name: Annotated[list[str] | None, typer.Option(
        "--auth-name", help="额外视为「等待授权」的进程名，可重复")] = None,
):
    if notify not in MODES:
        raise typer.BadParameter(f"可选 {', '.join(MODES)}", param_hint="--notify")
    try:
        keep = parse_duration(keep_done)
    except ValueError as e:
        raise typer.BadParameter(str(e), param_hint="--keep-done") from None
    th = Thresholds(confirm=confirm_after, gui=gui_after, listen=listen_after, hung_fg=hung_fg,
                    hung_bg=hung_bg, keep_done=keep)
    tracker = Tracker(PsutilProcs(), sessions_filter=session or [], th=th,
                      auth_names=AUTH_NAMES | frozenset(auth_name or []))
    if stream:
        from cctail.stream import run_stream
        raise typer.Exit(run_stream(tracker, Notifier(notify, _term_writer())))
    from cctail.tui import CcTailApp
    CcTailApp(tracker, notify_mode=notify).run()


if __name__ == "__main__":
    app()
```
